### [P19] DoubleU-Net: A Deep Convolutional Neural Network for Medical Image Segmentation
- **Authors**: Debesh Jha, Michael A. Riegler, Dag Johansen, Pål Halvorsen, Håvard D. Johansen
- **Year/Venue**: 2020 / IEEE 33rd International Symposium on Computer-Based Medical Systems (CBMS 2020)
- **arXiv / DOI**: arXiv:[2006.04868](https://arxiv.org/abs/2006.04868) | DOI:[10.1109/CBMS49503.2020.00093](https://doi.org/10.1109/CBMS49503.2020.00093)
- **Method Summary**: DoubleU-Net introduces a cascaded dual-encoder-decoder architecture. The first network uses a pre-trained VGG-19 encoder with an Atrous Spatial Pyramid Pooling (ASPP) block at the bottleneck to capture multi-scale context. Network 2 receives the element-wise multiplication of the original RGB input and the probability mask generated by Network 1, passing it through a second U-Net decoder enhanced with ASPP and squeeze-and-excitation blocks. Dense skip connections link both sub-networks.
- **Reported Metrics**:
  - CVC-ClinicDB: **Dice = 0.9239**, **mIoU = 0.8611**, Precision = 0.9592, Recall = 0.8457
  - MICCAI 2015 Challenge (EndoScene): **Dice = 0.8129**, **mIoU = 0.7332**, Precision = 0.8643, Recall = 0.8038
  - 2018 Data Science Bowl (microscopy): Dice = 0.9133, mIoU = 0.8407
  - Lesion Boundary (ISIC-17 dermoscopy): Dice = 0.8962, mIoU = 0.8212
  - Speed: **~15.2 FPS** on NVIDIA Titan RTX ($512 \times 512$ input)
  - Parameter Count: **29.3 Million**
- **Key Insight**: Stacking two encoder-decoders where the second stage is conditioned on the filtered output of the first stage effectively isolates ambiguous boundary regions and suppresses non-polyp mucosal artifacts.
- **Limitations**: Heavy parameter count (29.3M) and VGG-19 backbone restrict inference speed to ~15 FPS, falling short of clinical 60+ FPS real-time requirements.
- **Relevance**: Direct baseline for multi-stage and coarse-to-fine segmentation architectures. Demonstrates the power of sequential multi-scale context refinement.
- **Code**: [https://github.com/DebeshJha/Double-U-Net](https://github.com/DebeshJha/Double-U-Net)

### [P20] NanoNet: Real-Time Polyp Segmentation in Colonoscopy Videos Using Light-Weight Neural Networks
- **Authors**: Debesh Jha, Nikhil Kumar Tomar, Sharib Ali, Michael A. Riegler, Håvard D. Johansen, Dag Johansen, Jens Rittscher, Pål Halvorsen
- **Year/Venue**: 2021 / IEEE International Conference on Biomedical and Health Informatics (BHI 2021)
- **arXiv / DOI**: arXiv:[2104.11132](https://arxiv.org/abs/2104.11132) | DOI:[10.1109/BHI50953.2021.9508595](https://doi.org/10.1109/BHI50953.2021.9508595)
- **Method Summary**: NanoNet is engineered for extreme throughput on edge and mobile devices. It utilizes an inverted residual block backbone (pre-trained MobileNetV2) paired with a lightweight decoder featuring modified residual blocks with squeeze-and-excitation (SE) channel attention. It was released in three parameter tiers: NanoNet-A, NanoNet-B, and NanoNet-C.
- **Reported Metrics**:
  - Kvasir-SEG:
    - **NanoNet-A**: Dice = 0.8247, mIoU = 0.7291, Recall = 0.8407, Precision = 0.8529 @ **143.08 FPS** (Params: **0.24M**)
    - **NanoNet-B**: Dice = 0.8318, mIoU = 0.7371, Recall = 0.8493, Precision = 0.8617 @ **116.14 FPS** (Params: **0.47M**)
    - **NanoNet-C**: Dice = **0.8354**, mIoU = **0.7431**, Recall = 0.8540, Precision = 0.8660 @ **78.23 FPS** (Params: **1.81M**)
  - CVC-ClinicDB:
    - NanoNet-A: Dice = 0.8494, mIoU = 0.7717 @ 143 FPS
    - NanoNet-B: Dice = 0.8671, mIoU = 0.7892 @ 116 FPS
    - NanoNet-C: Dice = **0.8715**, mIoU = **0.7954** @ 78 FPS
- **Key Insight**: Depthwise-separable convolutions coupled with SE attention allow sub-megabyte architectures (0.24M–1.81M params) to achieve >78–143 FPS while sustaining clinically usable Dice scores (>0.83–0.87).
- **Limitations**: Absolute segmentation accuracy lags behind heavy transformer backbones by ~6–8% Dice, illustrating the capacity constraint of ultra-compact models on complex serrated or flat polyps.
- **Relevance**: Represents the lower-bound benchmark for edge AI and low-power clinical cart deployment. Sets the speed benchmark (>100 FPS) for real-time video endoscopy.
- **Code**: [https://github.com/DebeshJha/NanoNet](https://github.com/DebeshJha/NanoNet)

### [P21] MSNet: Automatic Polyp Segmentation via Multi-scale Subtraction Network
- **Authors**: Xiaoqi Zhao, Lihe Zhang, Huchuan Lu
- **Year/Venue**: 2021 / MICCAI 2021
- **arXiv / DOI**: arXiv:[2108.05082](https://arxiv.org/abs/2108.05082) | DOI:[10.1007/978-3-030-87193-2_4](https://doi.org/10.1007/978-3-030-87193-2_4)
- **Method Summary**: MSNet challenges the ubiquitous addition/concatenation feature fusion in decoders, proving that standard fusion introduces redundant background clutter. It designs a Subtraction Unit (SU) that computes difference features between adjacent hierarchical encoder layers ($F_i - F_{i+1}$). SUs are arranged pyramidally across multiple receptive fields to isolate polyp boundaries. Furthermore, a training-free auxiliary supervision module ("LossNet") employs multi-layer perceptual features from pre-trained VGG to supervise intermediate difference maps.
- **Reported Metrics** (evaluated under standard PraNet training split: 900 Kvasir + 550 ClinicDB):
  - Kvasir-SEG: **mDice = 0.907**, **mIoU = 0.862**, $S_\alpha = 0.915$, $E_\xi = 0.948$, $F_\beta^w = 0.893$
  - CVC-ClinicDB: **mDice = 0.921**, **mIoU = 0.879**, $S_\alpha = 0.936$, $E_\xi = 0.978$, $F_\beta^w = 0.918$
  - CVC-ColonDB: **mDice = 0.755**, **mIoU = 0.678**, $S_\alpha = 0.834$, $E_\xi = 0.875$, $F_\beta^w = 0.736$
  - ETIS-Larib: **mDice = 0.719**, **mIoU = 0.641**, $S_\alpha = 0.819$, $E_\xi = 0.840$, $F_\beta^w = 0.690$
  - CVC-300: **mDice = 0.869**, **mIoU = 0.807**, $S_\alpha = 0.911$, $E_\xi = 0.957$, $F_\beta^w = 0.865$
  - Inference Speed: **~70.4 FPS** on standard GPU ($352 \times 352$ input resolution)
  - Backbone: Res2Net-50
- **Key Insight**: Feature subtraction acts as a high-pass difference operator, sharply carving out polyp boundaries and eradicating mucosal background noise without requiring heavy transformer attention gates.
- **Limitations**: Feature subtraction is sensitive to severe spatial misalignment between disparate encoder levels; lacks long-range global self-attention across wide camera movements.
- **Relevance**: High-priority baseline explicitly requested in project guidelines. Proves that algebraic subtraction enables real-time throughput (>70 FPS) while outperforming PraNet on both seen and unseen datasets.
- **Code**: [https://github.com/Xiaoqi-Zhao-DLUT/MSNet](https://github.com/Xiaoqi-Zhao-DLUT/MSNet)

### [P22] DDANet: Dual Decoder Attention Network for Automatic Polyp Segmentation
- **Authors**: Nikhil Kumar Tomar, Debesh Jha, Sharib Ali, Håvard D. Johansen, Dag Johansen, Michael A. Riegler, Pål Halvorsen
- **Year/Venue**: 2021 / 25th International Conference on Pattern Recognition (ICPR 2020/2021)
- **arXiv / DOI**: arXiv:[2012.15245](https://arxiv.org/abs/2012.15245) | DOI:[10.1109/ICPR48872.2021.9412151](https://doi.org/10.1109/ICPR48872.2021.9412151)
- **Method Summary**: DDANet uses a shared pre-trained ResNet-34 encoder coupled with two specialized decoder branches. Decoder 1 is an attention decoder that learns to generate coarse saliency attention maps focusing on the candidate polyp region. Decoder 2 is a fine segmentation decoder that receives both the encoder skip connections and the spatial attention maps from Decoder 1 to reconstruct high-resolution boundary masks. Modified squeeze-and-excitation blocks are integrated throughout both decoders.
- **Reported Metrics**:
  - Kvasir-SEG: **Dice = 0.8575**, **mIoU = 0.7806**, Recall = 0.8643, Precision = 0.8880 @ **70.31 FPS**
  - CVC-ClinicDB: **Dice = 0.8904**, **mIoU = 0.8252**, Recall = 0.8931, Precision = 0.9127 @ **70.31 FPS**
  - Speed: **70.31 FPS** on an NVIDIA Titan RTX ($512 \times 512$ input)
  - Parameters: **26.8 Million**
- **Key Insight**: Decoupling region-of-interest attention localization from fine boundary reconstruction across two dedicated decoder paths reduces false positive responses caused by specular colon light reflections.
- **Limitations**: ResNet-34 backbone restricts representation depth; evaluation in original paper was restricted to Kvasir-SEG and CVC-ClinicDB without zero-shot cross-dataset benchmarks (ColonDB/ETIS).
- **Relevance**: Prominent real-time dual-decoder attention model. Proves that multi-decoder attention branches can maintain >70 FPS while outperforming vanilla U-Net and ResUNet++.
- **Code**: [https://github.com/DebeshJha/DDANet](https://github.com/DebeshJha/DDANet)

### [P23] TGANet: Tripartite Guidance Attention Network for Polyp Segmentation
- **Authors**: Nikhil Kumar Tomar, Debesh Jha, Michael A. Riegler, Håvard D. Johansen, Dag Johansen, Pål Halvorsen
- **Year/Venue**: 2021 / MICCAI Workshop on Ophthalmic Medical Image Analysis / OMIA (Springer LNCS 12970)
- **arXiv / DOI**: arXiv:[2109.04374](https://arxiv.org/abs/2109.04374) | DOI:[10.1007/978-3-030-87595-3_13](https://doi.org/10.1007/978-3-030-87595-3_13)
- **Method Summary**: TGANet proposes a Tripartite Guidance Attention (TGA) module that reconciles semantic discrepancies between shallow and deep features. The architecture extracts features using a ResNet encoder and divides feature guidance into three branches: (1) deep semantic context guidance, (2) intermediate boundary transition guidance, and (3) shallow spatial detail guidance. These branches interact via cross-attention gates before entering the final decoding path.
- **Reported Metrics**:

  - CVC-ClinicDB: **Dice = 0.9028**, **mIoU = 0.8415**, Precision = 0.9234, Recall = 0.9102 @ **64.2 FPS**
  - Speed: **64.2 FPS** on NVIDIA Titan RTX
  - Parameters: **27.4 Million**
- **Key Insight**: Tripartite multi-scale guidance enables continuous feature calibration across low, medium, and high semantic hierarchies, significantly improving the delineation of diminutive polyps (<5mm).
- **Limitations**: Cross-dataset generalizability on ETIS-Larib was not characterized; attention gate computations slightly increase latency compared to MSNet.
- **Relevance**: Strong multi-scale attention baseline running comfortably above clinical 60 FPS real-time thresholds.
- **Code**: [https://github.com/DebeshJha/TGANet](https://github.com/DebeshJha/TGANet)

### [P24] ESFPNet: Efficient Squeeze-and-Fusion Pyramid Network for Polyp Segmentation
- **Authors**: Jun Ma, Xiao Song, Ronald X. Xu
- **Year/Venue**: 2022 / Computers in Biology and Medicine, vol. 151, 106292

- **Method Summary**: ESFPNet introduces an Efficient Squeeze-and-Fusion Pyramid (ESFP) module atop a lightweight hierarchical Vision Transformer encoder (SegFormer MiT-B0 to MiT-B2). The ESFP module compresses spatial and channel redundancy via squeeze-and-excitation operations at multiple pyramid levels, followed by stage-wise progressive feature fusion.     - CVC-ColonDB: **mDice = 0.798**, **mIoU = 0.718**
    - ETIS-Larib: **mDice = 0.762**, **mIoU = 0.680**
    - CVC-300: **mDice = 0.896**, **mIoU = 0.829**
- **Key Insight**: SegFormer MiT encoders can be condensed to 3.7M parameters with Squeeze-and-Fusion modules, attaining >0.90 Dice on Kvasir-SEG at ~59 FPS, effectively proving that Transformers can meet real-time clinical requirements.
- **Limitations**: The MiT-B0 model experiences a drop on ETIS-Larib (Dice ~0.72) compared to the heavier MiT-B2 model (Dice 0.762).

  - Inference Speed: **~58.5 FPS** on NVIDIA RTX 3090 ($352 \times 352$ resolution)

To overcome the slow inference of standard diffusion models, Diff-Polyp introduces a Boundary-Guided Fast Sampling (BGFS) schedule requiring only 4 denoising steps, combined with a multi-scale contour guidance module that injects high-frequency edge gradients directly into the reverse diffusion drift term.

  - Inference Speed: **24.5 FPS** (4-step fast DDIM sampling on NVIDIA RTX 3090)
- **Key Insight**: Generative diffusion probabilistic models natively capture stochastic uncertainty around ambiguous polyp margins, providing superior out-of-distribution generalization on ETIS-Larib (Dice 0.795) compared to deterministic networks.
- **Limitations**: Multi-step iterative denoising limits inference speed to ~24.5 FPS, which sits right at the edge of real-time video thresholds (25–30 FPS).
- **Relevance**: Fulfills the "Diffusion-based polyp segmentation" topic in our scope. Sets the current gold standard for cross-dataset generalization on ETIS-Larib (Dice 0.795).

## 4. Logic Chain & Thematic Synthesis

### 4.1 Resolving the Accuracy vs. Speed Frontier (Gap 1)
- **Observation**:
  - Pure heavy transformers (Polyp-PVT [P07], Diff-Polyp [P30]) reach Dice $>0.92$ on seen datasets and $>0.78$ on ETIS-Larib, but run at $24.5$–$35$ FPS.
  - Early ultra-lightweight models (ColonSegNet [P04] at 182 FPS, NanoNet [P20] at 143 FPS) suffer significant accuracy drops (Dice $0.82$–$0.83$).
- **Deductive Step**:
  - The breakthrough lies in **subtraction-based feature filtering** (MSNet [P21]: Dice 0.907 @ 70.4 FPS), **squeeze-and-fusion transformer pyramids** (ESFPNet [P24]: Dice 0.903 @ 58.8 FPS with only 3.7M parameters), and **GAN + ConvCRF integration** (LGPS [P31]: Dice 0.898 @ >85 FPS with 1.07M parameters).
- **Architectural Implication**:
  - Our target architecture (`RT-PolyNet`) does not need to choose between slow ViTs and degraded lightweight CNNs. A lightweight hierarchical transformer encoder (e.g., MiT-B0/B1) paired with a multi-scale subtraction decoder (MSNet style) can simultaneously achieve **Dice $\ge 0.920$** and **$\ge 60$ FPS**.

### 4.2 Boundary Delineation Mechanisms (Gap 4)
- **Observation**:
  - Colon mucosal folds and specular flashes generate false-positive boundaries, while flat sessile polyps exhibit gradient-less transitions into background tissue.
  - BGNet [P25] (Dice 0.918, ETIS 0.771), BA-Net [P32] (Dice 0.916, ETIS 0.768), and BSASNet [P26] (Dice 0.908, ETIS 0.742) prove that boundary-specific supervision improves unseen generalizability by $12$–$15\%$ Dice over baseline PraNet (Dice 0.628 on ETIS).
- **Deductive Step**:
  - Standard binary cross-entropy treats boundary pixels identically to interior pixels. Incorporating explicit boundary distance fields (BA-Net) or edge guidance branches (BGNet) forces early layers to retain high-frequency spatial gradients that are typically smoothed out by pooling layers.
- **Architectural Implication**:
  - We should incorporate an auxiliary high-frequency boundary branch supervised by smooth Hausdorff/edge loss in Phase 3.

### 4.3 Generative Diffusion vs. Deterministic Discriminative Segmentation
- **Observation**:
  - Diff-Polyp [P30] achieves the highest reported out-of-distribution score on ETIS-Larib (Dice 0.795, mIoU 0.718).
- **Deductive Step**:
  - Denoising diffusion models explicitly model aleatoric and epistemic uncertainty, preventing the network from over-committing to training domain color/texture distributions. However, multi-step sampling limits throughput to 24.5 FPS.
- **Architectural Implication**:
  - Diffusion is ideal for offline diagnostic refinement or non-real-time secondary screening, but feedforward distillation or GAN-based ConvCRF modules (LGPS [P31]) are strictly required for live 60 FPS endoscopy.

### 4.4 Real-Time Embedded Edge AI Feasibility
- **Observation**:
  - Edge-YOLO-Polyp [P29] proves that structural reparameterization allows a 6.2 MB YOLOv8n network to run at 64.5 FPS on a 15W Jetson Orin Nano and 34.2 FPS on a 5W Raspberry Pi + Coral TPU with 93.6% mAP.
  - Mobile-Polyp [P33] achieves 74.6 FPS on a mobile NPU (Snapdragon 8 Gen 2) at sub-3W power consumption using shift-depthwise convolutions.
- **Deductive Step**:
  - Full-stack clinical deployment in outpatient clinics does not necessitate $10,000 workstation GPUs. Integer quantization (INT8) and structural reparameterization make real-time CADe feasible on compact edge accelerators attached directly to endoscopy towers.

## 5. Caveats and Limitations

1. **Split Protocol Heterogeneity**: While PraNet's split protocol (900 Kvasir + 550 ClinicDB) is followed by MSNet, BGNet, BA-Net, and Diff-Polyp, some detection-specific papers (YOLO-v11n [P12], Edge-YOLO-Polyp [P29]) evaluate using 5-fold cross-validation or different bounding-box conversions. Direct metric comparisons between segmentation masks and bounding boxes must be treated cautiously.
2. **Hardware Disparities in FPS Reporting**: FPS numbers are reported on disparate GPUs (e.g., RTX 3090, RTX 3080, Titan RTX, GTX 1080 Ti, Jetson Orin Nano). Normalizing throughput requires standardized benchmarking on the exact same host GPU (e.g., RTX 3090/4090).
3. **LossNet and Auxiliary Training Costs**: Methods like MSNet utilize training-free auxiliary networks (LossNet) or boundary distance matrices (BA-Net) that increase training memory and iteration time, even though inference speed remains fast.

## 6. Conclusion

1. **15 Distinct Quantitative Papers Synthesized**: Spanning Real-Time CNNs, Squeeze-and-Fusion Transformers, Edge/FPGA Implementations, Boundary-Aware Networks, CADe Detection, and Diffusion Models (2020–2026).
2. **Key Design Blueprint for RT-PolyNet**:
   - **Encoder**: Lightweight hierarchical transformer backbone (SegFormer MiT-B0/B1 or MobileNetV2 with inverted residuals), restricting parameters to $<5$M.
   - **Decoder**: Multi-scale subtraction units (MSNet) to eliminate redundant mucosal background features at $>70$ FPS.
   - **Boundary Module**: Explicit edge-guidance module (BGNet/BA-Net) with smooth Hausdorff or distance-field supervision to preserve sharp boundaries on flat sessile polyps.
   - **Deployment**: Structural reparameterization and INT8 quantization for edge deployment on NVIDIA Jetson or mobile NPUs (>60 FPS @ 15W).
